# 隔壁有只猫 · 官方下载

住在 macOS 菜单栏里的手绘小猫。官网：https://cat.manbangbang.com

本仓库仅用于分发测试安装包和安装说明，不公开应用源码。

## 0.1 测试版

- 支持 Apple Silicon（M 系列）Mac，macOS 14 或更新版本。
- 打开 DMG，将「隔壁有只猫.app」拖入 Applications，再从应用程序打开。
- 应用显示在屏幕顶部菜单栏，不显示 Dock 图标。
- 仅使用临时 ad-hoc 签名，未使用 Developer ID 签名，也未经过 Apple 公证。
- 首次打开可能被系统拦截。确认来源可信后，先尝试打开，再进入「系统设置 → 隐私与安全性」查看是否出现「仍要打开」。不需要关闭系统安全保护。
- 若系统提示恶意软件或文件损坏，请停止安装并反馈具体提示。
